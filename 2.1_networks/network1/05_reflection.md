## 🧠 5. Reflection Questions

### 5.1 What would happen if two PCs had the same IP address?
It will display IP already exists so we can never assign same ip to different devices.

### 5.2 Why do we use a switch instead of directly connecting PCs together?
it will take less copper wire which is cost efficient and there is only one ethernet point for each pc so could not connect all of them with each other.

### 5.3 What does the subnet mask 255.255.255.0 indicate?
The subnet mask 255.255.255.0 indicates that the first three octets of the IP address are the network portion, while the last octet is the host portion.
